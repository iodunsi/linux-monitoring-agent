# Linux Monitoring Agent

A lightweight Linux endpoint monitoring agent built with Python
and Bash to demonstrate system administration, automation,
and endpoint health monitoring.

## Features

- CPU utilization monitoring
- Memory usage monitoring
- Disk usage monitoring
- System uptime reporting
- Threshold-based health warnings
- Timestamped log output

## Tech Stack

- Python
- Bash
- Ubuntu Linux
- Git and GitHub
- psutil
- systemd (planned)

## Project Status

Version 1: Initial development.

## Goals

- Automate routine endpoint health checks
- Identify basic system resource issues
- Produce readable logs for troubleshooting
- Explore scheduled execution using systemd
